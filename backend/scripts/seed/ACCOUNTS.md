# Seed test accounts

Created by `npm run seed:test` (see `scripts/seed-test-data.ts`). The source of truth is
`scripts/seed/fixtures.ts` -- update this file if you change it.

**Password for every account: `password`**
Log in with the username, or with `<username>@backline.test`.

To change a band or venue's picture, log in as someone in that band or on that venue's team.
(M) marks the manager, the one with full control. Pictures you set are kept if you re-run the seed.

Quickest route to setting a lot of pictures: log in as the booker, promoter or sound engineer
in each city. Those three cover most of the city's venues. Band managers cover the rest.
